# Plug & Roll — Digital Audio Multi-Effect Device

Desktop stereo multi-effect unit built around the Daisy Seed.

Signal chain: Pre-Amp → Compressor 1 (FET/Opto) → Distortion/Overdrive →
4-Band Parametric EQ → Compressor 2 (VCA/Opto) → Chorus → Delay → Reverb.

- Requirements: [`docs/requirements.md`](docs/requirements.md)
- Hardware (KiCad, JLCPCB): `hardware/`
- Firmware (libDaisy / DaisySP): `firmware/`
